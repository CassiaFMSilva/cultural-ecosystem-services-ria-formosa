# Cultural Ecosystem Services from Geolocated Images 🌿

> **Status:** ongoing project.  
> This repository documents an open and reproducible workflow for organizing, classifying and analyzing geolocated images related to cultural ecosystem services.

## About the project

This project explores the use of geolocated images as indirect indicators of cultural ecosystem services in protected coastal landscapes.

The current case study focuses on the Ria Formosa Natural Park, Portugal. We use publicly available geolocated images from Wikimedia Commons to investigate how visual records shared on digital platforms can support the identification, classification and spatial analysis of cultural ecosystem services.

The workflow is being developed with a focus on open tools, reproducible methods and clear documentation, combining environmental data analysis, spatial thinking and ecosystem services classification.

## Research approach

Geolocated images are treated as indirect evidence of society-environment interactions, rather than direct measures of cultural ecosystem services.

The images are organized and classified using an adapted CICES framework, considering visual elements related to recreation, aesthetic appreciation, nature observation, education and knowledge, cultural heritage, tourism and leisure, symbolic values and other cultural manifestations associated with the landscape.

This approach recognizes that images shared on digital platforms do not represent all cultural values associated with a landscape. Instead, they provide a complementary source of information that can help identify visible patterns of human perception, use and interaction with protected areas.

## Study area

The case study is located in the Ria Formosa Natural Park, a protected coastal landscape in southern Portugal.

The study area boundary is based on official protected area spatial data provided by ICNF/RNAP. The spatial layer is used to delimit the area of interest, support spatial queries and retain only geolocated images located within the protected area.

## Data sources

This workflow uses two main public data sources:

- Official protected area boundary data from ICNF/RNAP;
- Geolocated image metadata retrieved from Wikimedia Commons.

The Wikimedia Commons API is used to retrieve image metadata, geographic coordinates, upload information, licenses, image URLs and thumbnail URLs.

## Workflow

The analytical workflow includes:

1. Delimitation of the study area using an official protected area boundary;
2. Spatial queries to retrieve geolocated images from Wikimedia Commons;
3. Temporal filtering considering images made available in the last 20 years;
4. Spatial filtering to retain only images located within the study area;
5. Organization of metadata, thumbnails and image links into a structured database;
6. Visual classification of images using an adapted CICES framework;
7. Synthesis of cultural ecosystem service indicators through tables, graphs and exploratory maps.

## Project status

This project is currently under development. Scripts, documentation and outputs are being organized progressively as the research workflow advances.

At this stage, the repository focuses on documenting the methodological structure and reproducible workflow used to organize image metadata, support classification procedures and summarize cultural ecosystem service categories.

Future updates may include additional spatial analyses, classification agreement assessment, refined visual interpretation procedures and synthesis outputs related to cultural ecosystem service patterns.

## How to run

To reproduce the workflow:

1. Clone this repository.
2. Open the project in R or RStudio.
3. Install the required packages listed below.
4. Run the scripts in the `R/` folder following their numerical order.
5. Outputs will be saved in the `outputs/` folder.

Some raw, intermediate and thumbnail files are not stored directly in the repository, but can be reproduced from the scripts using public data sources.

## Tools and methods

The workflow is developed mainly in R, using open-source tools and packages for spatial analysis, API requests, data organization and visualization.

Main R packages include:

- `sf`
- `dplyr`
- `purrr`
- `httr2`
- `jsonlite`

- `ggplot2`

- `mapview`

## Main outputs

The workflow generates different types of outputs, including:

- Processed spatial files for the study area;
- Image metadata tables;
- Spatial layers with geolocated image points;
- Summary tables;
- Exploratory maps;
- Temporal distribution graphs;
- Image classification sheets;
- Calibration tables;
- Classification batches for collaborative visual interpretation.

Output files are saved in the `outputs/` directory.

## Data availability and image use

This workflow uses public geolocated image metadata retrieved from Wikimedia Commons and official spatial data for protected area boundaries.

Thumbnail images are used to support visual interpretation and classification procedures. Image files and metadata should always be interpreted according to their original licensing terms provided by Wikimedia Commons.

Raw and intermediate files may not be fully versioned in this repository to avoid storing large or reproducible files. When possible, these files can be regenerated by running the scripts.

## Open science and reproducibility

This repository is part of an effort to document research workflows using open and accessible tools. The project prioritizes free and open data sources, reproducible scripts and transparent methodological decisions.

The aim is to make the analytical process easier to understand, review, adapt and reuse in future studies on cultural ecosystem services and spatial environmental analysis.
